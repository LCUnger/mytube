# MyTube

Choose what appears on YouTube and when the next video starts. MyTube keeps Home and Subscriptions available by default, filters out Shorts and community posts, blocks identifiable ads, and stops after each video, including inside a playlist.

## Install on desktop

1. Download and extract the project source, or extract the MyTube release ZIP to a permanent folder.
2. Open `edge://extensions` in Microsoft Edge or `chrome://extensions` in Chrome. Turn on **Developer mode**.
3. Select **Load unpacked**. From the source tree choose **extension**. From the release ZIP choose the extracted folder containing **manifest.json**.
4. Reload any open YouTube tabs. Open **Extensions → MyTube** to change your settings. You can also open **Extension options** from the browser’s extension details page.

Keep the extracted folder where it is while using the extension. To update an unpacked installation, replace its files, click **Reload** on the extension card, then refresh YouTube.

## Controls

| Switch | What changes | Initially |
| --- | --- | --- |
| Block YouTube ads | Blocks identifiable ad requests, hides sponsored placements and uses visible player skip controls | On |
| Hide Shorts | Removes Shorts shelves, feed tiles and navigation entries. Direct Shorts links still open | On |
| Hide community posts and polls | Removes post and poll cards from mixed feeds as they load | On |
| Stop after each video | Stops ordinary watch-page videos from advancing, including playlist items. Use Play to replay or Next to continue | On |
| Hide comments | Collapses comment threads and mobile comment entry points | Off |
| Hide Explore and Trending | Removes matching navigation entries and sections | Off |
| Hide More from YouTube | Removes the desktop guide section for other YouTube products | Off |
| Hide annotations | Removes player annotations, branding overlays and info-card teasers | Off |
| Hide video sidebar | Hides the desktop watch sidebar, including its playlist panel, and mobile related-video sections | Off |
| Hide Home feed | Hides the Home recommendations while leaving search and navigation available | Off |
| Hide end-screen recommendations | Hides the suggested-video wall at the end of playback | Off |
| Hide creator end-screen cards | Hides creator-placed cards over the closing seconds of the video | Off |
| Hide Mixes | Removes radio and autogenerated Mix tiles | Off |
| Hide video information | Collapses the watch-page title, channel details, action row and description | Off |
| Hide merch, tickets and offers | Removes recognized shopping and ticket shelves | Off |

Switches take effect in open tabs. A request the browser already sent cannot be withdrawn. Reload the video when comparing ad-blocking settings.

## Browser and playback coverage

The extension targets desktop Edge and Chrome and the browser version of YouTube at **m.youtube.com** on Edge for Android. The Android layout has fixture coverage. Physical-device installation and playback still need verification. There is currently no published MyTube store listing. The native YouTube app is outside the extension's scope.

YouTube varies its layout and ad delivery across accounts, regions and videos. Inline ads that share a video stream and have no skip control can still play. Creator sponsorships recorded into videos are part of the recording. The stop control operates on finite watch-page videos by intercepting the end-of-video event before it reaches the player. Live streams and the Shorts player use separate playback flows.

If something slips through, include the browser version, desktop or mobile site, page type, enabled switch, and what remained visible in a bug report. Remove account details from screenshots.

## How it works

The settings panel saves one Boolean per switch in local extension storage. Open tabs listen for changes. CSS targets individual YouTube cards and shelves, including cards added during scrolling. A route marker distinguishes Home from Subscriptions when YouTube navigates without reloading the document.

A content script handles playback events. A background service worker keeps Chromium's bundled network rules in sync with the ad switch. All runtime code and icons ship in the extension. See the [privacy policy](PRIVACY.md).

## Build and test

Python 3.9+ builds the ZIP without installing any packages. From the project root run:

```sh
python3 scripts/package.py
```

The release is written to `dist/mytube-1.0.0.zip`. To run the local checks with Node.js 22+ and Python in a virtual environment:

```sh
node --test tests/*.test.cjs
python -m pip install beautifulsoup4==4.13.4
python tests/filters.py
```

The GitHub Actions workflow also loads the extracted ZIP in Chromium, tests settings persistence and live filtering on desktop and mobile fixture pages, and captures a 1280 × 800 screenshot of the real settings panel. For the same browser check locally:

```sh
npm install --no-save --package-lock=false playwright@1.56.1
npx playwright install chromium
node tests/browser.cjs
```
